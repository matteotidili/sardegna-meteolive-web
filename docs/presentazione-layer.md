# Mappa interpolata della Sardegna

La mappa stimata usa il multipoligono del confine regionale ISTAT (codice 20), edizione 1 gennaio 2026, estratto senza semplificazione aggiuntiva dalla copia WGS84 di geojson-italy. Il file include 183 poligoni. Dati ISTAT tramite geojson-italy, licenza [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). La geometria viene applicata dopo il calcolo del campo e prima della composizione sul basemap. La sfumatura grafica usa il colore dei campioni con supporto sufficiente e conserva il metodo, le scale, le unità e le osservazioni originali.
